Privacy note

This is for "gws CLI", a command-line tool I run on my own computer to work with my own Google account. Nobody else uses it, and it isn't offered to the public.

What it can reach

My own Gmail (reading, drafts and sending), my own Google Calendar, and my own Google Drive. Only my account, and only when I run it.

Where the data goes

Nowhere else. It talks to Google directly from my computer. Nothing is stored on any server of mine, sold, shared, or used for ads or for training AI models. The sign-in it keeps is stored encrypted on my own computer, and I can remove it at any time, either with gws auth logout or from my Google account's security settings.

Google API data

Its use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
